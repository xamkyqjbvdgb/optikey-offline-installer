![Category](https://img.shields.io/badge/Accessibility-blue?style=flat-square)

## About

OptiKey is a free, open-source on-screen keyboard for Windows designed for users with motor neuron disease (MND/ALS) and other motor impairments. Controlled entirely by eye-tracking hardware, OptiKey enables typing and mouse control for users who cannot use conventional input devices. Developed specifically for the ALS community, OptiKey is a life-enabling assistive technology tool.

## Common Problems & Limitations

- **Eye Tracking Required** — Full functionality requires compatible eye-tracking hardware
- **Windows Only** — No cross-platform version
- **Eye Tracking Fatigue** — Extended eye-tracking use can cause fatigue
- **Calibration Required** — Eye tracking hardware requires regular calibration for accuracy
